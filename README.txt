ELIJAH GABRIEL PORTFOLIO

Files:
- index.html  -> main website
- style.css   -> layout, colors, responsive design, animations
- script.js   -> mobile menu, project popups, reveal animation, current year

How to open:
1. Keep all three files in the same folder.
2. Double-click index.html, or open it with a browser.

Notes:
- The contact email and social links are placeholders and can be replaced in index.html.
- The visual project cards are CSS-based placeholders, so the site works without an assets folder.
